Sniper Hunter helps streamers identify repeat opponents and possible stream snipers, while giving every Fortnite player a clear way to track their games. It reads completed replays, organizes matches and players in a database on your computer, and displays the results in your browser. Your history and settings stay in the program folder.

Features

Last match and replays

  • Match statistics, platform distribution, repeat opponents, searchable elimination feed, and sortable team rosters with team-coloured portraits.
  • Click players or teams to filter the feed; right-click names to copy them and open player profiles from team cards.
  • Movement map with replay-time playback, player following, storm and visibility shading, trails, zoom, pan, and three-point alignment per saved map. Older matches reload movement only while their replay file remains in Fortnite Demos.
  • Browse adjacent replays in the current game list or filtered player history.

Recent games

  • Fast search, date and placement filters, clickable game totals, wins, kills, KD, and filtered time played.
  • Delete games or import a previous database.

Snipers list and player profiles

  • Search and sort large player histories; filter by platform or AI and see skin and platform icons.
  • View shared games, encounter and teammate incident counts, placement filters, and Fortnite Tracker links.

Add replay

  • Drag and drop replay files or select them from Fortnite Demos; automatic detection handles new completed replays.
  • Background parsing keeps pages responsive, retries files still being written, skips duplicate game IDs, and reports batch progress and errors.

Custom SQL

  • Browse database tables, run and save queries, and export results as CSV.

Settings

  • Accounts, network and optional read-only proxy access, automatic navigation, and a live local Console.
  • Portable database, skins, and one config.json beside the executable; automatic missing-skin downloads and database recovery prompts.
  • Fixed replay status bar, optional themed cursors, Back to top placement, tray controls, and optional one-click GitHub release updates.
